# Estudos de JavaScript

Exercícios do meu estudo de JavaScript, com foco em automação de testes.

Sou QA e estou migrando do teste manual para automação com Playwright. Este repositório guarda os exercícios que faço enquanto aprendo a linguagem — cada arquivo corresponde a uma aula, com comentários explicando o que entendi.

## Como rodar

Precisa do Node.js instalado.

```bash
node Aula05.js
```

## O que tem aqui

| Arquivo | Assunto |
| --- | --- |
| `Aula04.js` | Primeiro script e conversão de texto para número |
| `Aula05.js` | Variáveis, `let` e `const`, tipos primitivos e `typeof` |
| `Aula06.js` | Conversão de tipos, concatenação e formatação de texto e número |
| `Aula07.js` | Operadores aritméticos, ordem de precedência e auto-atribuição |

## Como estudo

- Assisto à aula pausando e digitando junto, nunca só assistindo
- Provoco erros de propósito para entender as mensagens
- Comento o código explicando **por que** está assim, não o que ele faz
- Anoto à parte os pontos que valem revisão
